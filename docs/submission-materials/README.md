# 项目答辩与竞赛资料

本目录汇总项目答辩演示稿、竞赛资料包和补充交付材料。内容来自工作区中的 `资料包/`、答辩文件与 `浙江工业大学 A14 序衡/作品材料电子版/`。重复的 `资料包_副本/` 未另建副本；完整竞赛资料 ZIP 也保留，方便整包下载。

- `资料包/`：产品手册、项目介绍、团队文档、报名材料、答辩 PPT 与操作视频。
- `答辩PPT/`：现行答辩稿、5 分钟版及 PDF 备用稿、项目计划书答辩稿、较早的 5.28 版本和演讲稿。
- `附加材料/`：自愿补充的工程源代码压缩包及 IndusOpt 数据优选 Skill 材料。

操作视频和 5.28 旧答辩稿超过 GitHub 普通 Git 的单文件大小限制，使用 Git LFS 保存；克隆后需安装 Git LFS 才能取回文件内容。
