# IndusOpt 工业建模数据优选与诊断 Skill

## 材料定位

本材料对应 A14 项目的“团队自愿提交的其他补充材料”，将 IndusOpt 已有工业数据处理能力整理为可安装的 Skill。用户通过支持 Skill 的智能体提出分析需求，由 Skill 指导参数核对、调用项目后端并整理交付结果。Skill 的价值在于流程复用、受约束执行和可复核交付；D-最优优选与 ARX 辨识仍由原项目实现，不将接口包装另行声称为算法创新。

本包包含可执行客户端、使用规范、合成示例、真实接口响应、成功与失败案例及验证程序。它需要搭配项目后端，不能脱离后端独立完成数值计算。

Skill 公开发布；主系统及 backend 当前不公开，在线运行限已有 backend 使用授权的成员。当前 Skill 正式使用 ARX 对照，尚未接入主系统新增的 OE。

## 提取出的工作流程

用户提供 CSV，并明确时间列、输入输出变量和补偿时滞。系统登记数据、核对版本与原文件一致性，输出质量画像；用户认可具体时滞方案后，创建保留来源关系的派生版本。随后执行共线性诊断、训练区间内的数据优选、同结构模型对照和数据导出。

Skill 将任务约束写入 SKILL.md，将反复使用的接口调用和验证逻辑写入 Python 脚本。客户端不自行实现辨识算法，也不要求额外的大模型 Key。智能体负责理解任务和解释结果，固定脚本负责调用服务、保存证据与检查交付文件。

模型评价采用按时间划分的训练、验证和保留测试区间。本快捷流程只使用验证指标作对照，未读取测试段评价；补偿后的模型采用零附加时滞，避免重复补偿。优选样本保留其在连续建模源数据中的行下标，不把不连续片段拼接为连续序列。

## 完整交付内容

- indusopt-data-selection：可安装 Skill，包含 SKILL.md、界面元数据、标准库客户端和接口说明。
- 示例与实测：S2 完整流程、S6 秩亏停止案例、未确认停止案例及项目内置基准响应；全部数据为仿真生成。
- 验证：原始与修订验证用例、历史运行记录，以及 2026-10-07 最新 backend 的 S2 在线验收证据。
- 使用说明：安装方法、演示启动与复现命令。

成功流程输出优选 CSV、原始上传副本、连续建模源数据、模型对照、逐步接口响应和 manifest。manifest 保存版本、运行标识、模型参数、选中行下标及文件 SHA-256。报告中的指标直接来自后端计算，不由语言模型编造。

## 9 月历史实际验证

在隔离的本地 SQLite 演示服务中，使用项目真实 FastAPI 与算法实现完成调用。S2 示例为 2,000 行、三个输入，固定随机种子 20260913；为测试操作链路，三个输入的补偿均明确设为 1 个采样点，未读取仿真真值来配置模型，也不宣称已恢复正确时滞。模型为 na=2、各输入 nb=2，选段窗口 60、预算 8，采用 OLS。

| 对照方案 | 实际训练行数 | 验证自由仿真 FIT | 验证一步预测 FIT |
|---|---:|---:|---:|
| 全量训练 | 1195 | 71.3998 | 96.9447 |
| D-最优选段训练 | 360 | 73.6591 | 96.9476 |

两组模型在本次运行中均稳定。此表证明接口链路可运行、指标可追查，不能推广为所有工业数据上的性能承诺。导出 CSV 已与建模源版本按选中下标逐行核对时间与数值。

S6 在同样固定参数下，选段模型返回 DESIGN_MATRIX_RANK_DEFICIENT；Skill 保留错误并停止，未输出成功 manifest 或优选 CSV。未确认案例仅形成接入、画像和待确认记录，未发送补偿或建模请求。另完成空选段、4,000 行下标截断、重复或负下标、路径越界、远程主机拒绝及时间戳异常等检查，共 10 项通过。Skill 结构验证通过。

## 使用边界与后续扩展

历史 SQLite 演示与最新 Docker S2 验收均覆盖脚本到真实后端的执行链路，未评测不同智能体的自然语言触发准确率；最新 S2 通过不代表数据库迁移、异步 worker 或生产部署验收。Skill 当前面向本机、规整后的 UTF-8 CSV；不自动清洗、删列、估计时滞或执行 Optuna 闭环寻优，这些仍由项目主体提供。

当前后端要求建模数据具有时滞补偿血缘，同时拒绝创建全零时滞补偿版本，因此全零时滞输入在此快捷流程中会停止并报告限制。Skill 不通过伪造补偿参数绕过规则。后续可在主项目完善相关版本处理后，扩展零时滞建模、长任务查询与远程产物下载，并继续以真实运行证据验证。
