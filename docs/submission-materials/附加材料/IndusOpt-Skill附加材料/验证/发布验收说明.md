## 复验命令

仅限已获非公开后端使用授权的成员：在本包根目录，使用已经安装后端依赖的 Python 3.11+ 执行。将下方示例后端路径替换为实际路径：

```text
python -B 验证/verify_live.py --backend "C:/path/to/IndusOpt/backend" --out runs/live-verification
```

`--out` 必须不存在。脚本使用空闲本地端口、新建临时数据库，保留临时状态便于调查；只关闭自己创建的进程。不要将在线复验脚本指向不可信后端源码。

文件改动完成后更新校验值，再进行只读核对：

```text
python -B 验证/check_package.py --update
python -B 验证/check_package.py
```
