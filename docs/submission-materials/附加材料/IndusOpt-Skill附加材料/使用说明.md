# 使用说明

## 安装 Skill

将本包的 `indusopt-data-selection` 文件夹复制到支持本地 Skill 的智能体技能目录。Codex 的通常位置为 `~/.codex/skills/`。不要覆盖已有同名修改版；可先比较内容。

新建任务或刷新技能发现后，可输入：

> 使用 $indusopt-data-selection 分析这份工业 CSV，先核对变量和时滞，完成诊断、数据优选和模型对照，输出可复核的结果。

自然语言调用依赖宿主智能体。脚本本身不解析自然语言，也无需提供外部大模型密钥。

## 后端与演示

Skill 公开发布，可下载、阅读、安装和二次开发；IndusOpt 主系统及 backend 当前不公开，也不随本包分发。已获主系统使用授权的成员可在已有 `backend/` 环境运行；仅下载公开 Skill 不能独立执行工业算法。启动命令与参数参见 `indusopt-data-selection/references/runtime.md`（含 Windows CMD 与 macOS/Linux）。9 月原始与修订验收作为历史记录保留；2026-10-07 最新 backend 的 S2 完整在线验收已通过，见 [发布验收说明](验证/发布验收说明.md) 和 [最新证据](验证/2026-10-07最新版兼容性复验/verification.json)。当前 Skill 正式使用 ARX 对照，尚未接入主系统新增的 OE。

可直接使用 `示例与实测/S2输入/input.csv`，也可运行 `generate-example --scenario S2` 重新生成。先建立独立演示目录，再启动后端；不要让演示脚本指向业务数据库或既有产物目录。

参数必须明确给出：CSV 文件、时间列、输入输出列、各输入时滞、数据性质、服务地址、对应的本机产物根目录和新输出目录。示例参数只用于演示，不是实际工业数据的默认选择。

## 评委演示建议

1. 查看 Skill 的 SKILL.md，说明它如何把任务需求连接到已有算法。
2. 对 S2 示例执行不带 --confirm-lags 的 analyze，查看质量画像、具体待确认参数与停止状态。
3. 认可示例的固定补偿方案后，使用新输出目录并加 --confirm-lags，展示 report.md、selected.csv、comparison.json 和 manifest.json。
4. 查看历史 S6 失败案例，说明该版本为何停止，以及为何没有改用全量样本或默默切换估计器；它不是最新版 backend 必须复现的结果。
5. 如需展示原项目的方法对照，再运行 benchmark。它与 CSV 快捷流程是两类实验，不混用结果。

## 验证

在解压目录执行：

```bash
python3 验证/test_adapter.py
```

该命令检查适配器约束以及附带的真实运行证据，不会启动后端或重跑全部算法。要重跑在线流程，使用 runtime.md 中的命令并指定全新输出目录。服务端生成的 UUID 与时间会变化，不能要求逐字一致。

原始 10 项验证记录保留在 `验证/测试结果.txt`；修订后测试及在线复验见 `验证/发布验收说明.md`。Windows 不具备符号链接权限时只跳过该子项，普通路径越界检查仍执行。测试通过不代表生产认证。服务未启动、接口版本不匹配、全零补偿、数据不规整、选段不完整、模型失败或导出不一致时，查看 failure.json 及对应 error.txt；不应将半成品作为成功结果提交。

## 文件解释

- source.csv：上传文件的逐字副本。
- model-source.csv：补偿后的完整连续版本，训练下标相对于此文件的数据行，从 0 开始，不含表头。
- selected.csv：后端正式导出的优选子集；不能将断续片段拼接后直接作为连续 ARX 训练输入。
- manifest.json：仅完整流程成功时产生，含校验值、行下标和参数来源。
- server-manifest.json：后端导出的来源记录。
- report.md、comparison.json：确定性报告及精确指标值。
- 带步骤编号的 JSON、requests.json：原始响应与调用参数，便于复核。

公开附件只使用合成示例。将来对真实业务 CSV 运行后，输出目录会包含数据副本，分享时应按用户授权范围选择文件。
